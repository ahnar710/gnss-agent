# GNSS 文献调研 Agent — 使用说明（1 页速览）

> 面向：产品经理 / 研发同事（无需任何编程基础）
> 版本：v0.2.0

## 这是什么

一个跑在你自己电脑上的文献调研助手：输入一句调研主题（或上传论文 PDF），
它会自动检索全球学术库、逐篇阅读、生成**中文调研报告**，24 小时内可完成 ≥100 篇文献的深度调研。**所有数据只存在你自己的电脑上。**

---

## 第一步：安装

| 你的系统 | 怎么做 |
|---|---|
| **Windows** | 双击 `GNSS文献调研Agent_Setup_x.x.x.exe` → 一路"下一步" → 桌面图标启动 |
| **macOS** | 解压压缩包 → 把 `GNSS文献调研Agent.app` 拖进"应用程序" → 双击启动（首次若提示"无法验证开发者"，右键 → 打开） |

启动后浏览器会自动打开 `http://127.0.0.1:8765`，这就是使用界面。

## 第二步：配置（只需一次，约 2 分钟）

1. 点右上角 **⚙ 设置**
2. 申请你自己的大模型 API Key（**费用自付，按量计费，很便宜**）：
   - 推荐 [DeepSeek 开放平台](https://platform.deepseek.com/)（国内可用，100 篇深读约 1~2 元）
   - 注册 → 充值（几块钱就够试）→ 创建 API Key → 复制
3. 设置页填入：API Base URL（DeepSeek 默认已填）、API Key、模型名（`deepseek-chat`）
4. 点 **测试连接** → 显示"✅ 连接成功" → **保存**

> Key 只保存在你自己电脑上，不会上传到任何服务器。

## 第三步：使用

- **新建调研**：点右上角「＋ 新建调研」→ 输入主题（或用示例一键填入）→ 开始调研
- **上传自己的论文**：进入任务页 → 点「📄 上传论文(PDF)」→ 选一个 PDF，自动提取并深读
- **查看进度**：左侧任务列表实时显示"已检索 / 相关 / 已深读 / 目标"
- **停止**：随时点「■ 停止调研」→ 自动生成最终报告（可复制 / 下载 .md）

## 数据与隐私

| 内容 | 存放位置 |
|---|---|
| 任务 / 论文 / 报告 / 上传的 PDF | 你的电脑（Windows: `C:\Users\你的用户名\.gnss_agent`，macOS: `~/.gnss_agent`） |
| 大模型调用 | 用**你自己的 Key** 直连 DeepSeek/OpenAI，不经过任何第三方 |
| 文献检索 | 检索词发往公开学术库（OpenAlex/arXiv 等），仅查询公开数据 |

**备份 = 把 `.gnss_agent` 文件夹拷走**；换电脑 = 拷过去，任务报告全在。

## 常见问题

- **任务能跑多久？** 默认 24 小时上限；达标 100 篇后继续扩展，直到你点停止、超时或达到成本上限（设置里可改，默认 $10 保险丝防烧钱）。
- **关掉浏览器/重启电脑会丢吗？** 不会，任务在后台保存，重开自动继续。
- **费用？** 只花你自己的 API Key 费用（文献源全免费）。100 篇深读用 DeepSeek 约 1~2 元；设置页有实时费用显示和成本上限。
- **双击没反应？** 多半被杀毒软件拦截 → 加入白名单；日志在 `.gnss_agent\app.log`。
